Place - Mentor 🎓
The Ultimate Career Readiness & Campus Recruitment Suite

Place - Mentor is a comprehensive Android application designed to streamline the campus recruitment process. 
It bridges the gap between students, TPO (Training & Placement Officers), and recruiters by providing a centralized hub for job listings, resume building, and interview scheduling.

🚀 Key Features

Student Dashboard: Track application statuses, upcoming interviews, and skill assessments in real-time.

Resume Builder: Integrated ATS-friendly resume generator with customizable templates.

TPO Admin Panel: Manage student eligibility, verify documents, and export placement reports.

Recruiter Portal: Post job descriptions, filter candidates based on CGPA/skills, and schedule rounds.
